# Дорама за 5 — Studio

Локальная AI-студия для поиска тем о китайских дорамах, создания пятиминутных
вертикальных видео, озвучки, субтитров и контролируемой публикации на YouTube.

![Баннер Дорама за 5](assets/branding/banner-dorama-za-5-2560x1440.jpg)

Проект работает на компьютере пользователя: исходные видео, токены и очередь
публикации не отправляются в этот репозиторий. Перед публикацией каждый ролик можно
просмотреть, отредактировать или отклонить.

> [!IMPORTANT]
> Используйте только собственные материалы, public domain или видео с лицензией,
> разрешающей переработку. Открытая ссылка не означает разрешение на скачивание и
> повторную публикацию.

## Возможности

- мультиплатформенный радар: YouTube, Bilibili, Dailymotion, Internet Archive и
  Wikimedia Commons;
- расширение русскоязычного запроса английскими и китайскими вариантами;
- автоматическая проверка CC BY, CC BY-SA, CC0/public domain и разрешённых каналов;
- загрузка своей серии или трейлера и хронологический пересказ ровно на 5 минут;
- автоматический выбор сцен, русская озвучка и вшитые субтитры;
- Edge TTS с проверкой произношения через Whisper;
- очередь ручной проверки и адресная отмена отдельных процессов;
- атомарная защита от двойной публикации при параллельных запусках;
- официальная загрузка на YouTube через OAuth 2.0;
- публикация по расписанию через Windows Task Scheduler;
- локальный интерфейс по адресу `http://127.0.0.1:8765`.

## Как устроены источники

| Источник | Метаданные для радара | Автоскачивание |
|---|---:|---:|
| YouTube | Да | Только Creative Commons или разрешённый канал |
| Bilibili | Да | Нет |
| Dailymotion | Да | Нет |
| Internet Archive | Да | Только совместимая открытая лицензия |
| Wikimedia Commons | Да | CC BY, CC BY-SA, CC0 или public domain |

Лицензии с ограничениями `NC` (некоммерческое использование) и `ND` (без
производных работ) автоматически отклоняются. Вместе со скачанным разрешённым
файлом сохраняется JSON с автором, ссылкой и основанием использования.

## Системные требования

- Windows 10/11 x64;
- Python 3.12;
- минимум 16 ГБ RAM, рекомендуется 24–32 ГБ для `Whisper medium`;
- 10–20 ГБ свободного места для моделей и временных файлов;
- [Ollama](https://ollama.com/download) и модель `qwen2.5:7b`;
- интернет для поиска, Edge TTS, первого скачивания Whisper и YouTube API.

Отдельно устанавливать FFmpeg не требуется: бинарник предоставляет
`imageio-ffmpeg`.

## Быстрый запуск

### 1. Клонирование и окружение

```powershell
git clone https://github.com/Gabriel329-bot/dorama-za-5-studio.git
cd dorama-za-5-studio
py -3.12 -m venv venv
venv\Scripts\python.exe -m pip install --upgrade pip
venv\Scripts\pip.exe install -r requirements.txt
Copy-Item .env.example .env
```

Для NVIDIA GPU на Windows установите официальный CUDA runtime внутрь окружения проекта:

```powershell
venv\Scripts\pip.exe install -r requirements-cuda.txt
```

Системный CUDA Toolkit для этого варианта не требуется. Если CUDA-зависимости не
установлены, программа автоматически продолжит распознавание на CPU.

### 2. Локальная модель сценариев

Установите Ollama, затем выполните:

```powershell
ollama pull qwen2.5:7b
```

Для компьютера с небольшим объёмом RAM можно использовать:

```powershell
ollama pull qwen2.5:3b
```

После этого поменяйте `highlight.model` в `config.yaml` на `qwen2.5:3b`.

### 3. Запуск панели

Дважды щёлкните `start-dashboard.cmd` или выполните:

```powershell
venv\Scripts\python.exe -m webapp
```

Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765).

При первом распознавании `faster-whisper` скачает модель. Это большой файл и
может занять несколько минут. Необязательный read-токен Hugging Face можно
записать в `.env`:

```dotenv
HF_TOKEN=your_own_token
```

## Основные режимы

### Мультиплатформенный радар

Радар получает только названия, описания, счётчики и ссылки. Чужие видео в этом
режиме не скачиваются. По найденным сигналам локальная модель создаёт оригинальный
сценарий, после чего система делает озвученный вертикальный выпуск.

Лимит в интерфейсе применяется к каждому источнику. Например, значение `10`
может дать до 50 сигналов. Ошибка одной площадки не останавливает остальные.

Команда:

```powershell
venv\Scripts\python.exe cli.py dorama --query "исторические китайские дорамы" --limit 10
```

### Автопоиск разрешённого видеоряда

Система проверяет YouTube, Wikimedia Commons и Internet Archive. Скачивание
начинается только после машинной проверки лицензии.

```powershell
venv\Scripts\python.exe cli.py licensed --query "китайская историческая дорама" --limit 10
```

Современных дорам с открытой лицензией мало. Если подходящий материал не найден,
задача завершится безопасной ошибкой, а нелицензированные результаты останутся
только ссылками.

### Своя серия → 5 минут

1. Поместите видео в `input/` или загрузите его через панель.
2. Подтвердите наличие прав.
3. Агент распознает речь, построит таймлайн и выберет сцены.
4. Локальная модель напишет последовательный русский пересказ.
5. Система добавит озвучку, субтитры и соберёт вертикальное видео 1080×1920.

```powershell
venv\Scripts\python.exe cli.py episode input\episode.mp4 --focus "интрига без раскрытия финала"
```

Длительность готового ролика задаётся параметром
`episode.target_duration_seconds` и по умолчанию равна 300 секундам.

### Нарезка собственных длинных видео

```powershell
venv\Scripts\python.exe cli.py clip input\source.mp4
```

Whisper создаёт транскрипт с таймкодами, Ollama выбирает самостоятельные отрывки,
а FFmpeg собирает вертикальные клипы с подсветкой слов.

## Фоновые задачи и отмена

В панели отображаются текущий этап, прогресс и последнее сообщение. Кнопка
**«Отменить»** действует только на выбранную задачу:

- ожидающая задача удаляется из очереди;
- скачивание прекращается; проверенный `.part` разрешённого источника сохраняется для продолжения;
- дочерний процесс FFmpeg или yt-dlp завершается;
- остальные задачи продолжают работать.

## Озвучка

Стандартный пресет `tiktok_story` использует `ru-RU-DmitryNeural`, скорость
`+12%` и высоту `-2Hz`. После синтеза Whisper сравнивает озвучку со сценарием.
Если точность ниже `dorama.tts_qa_min_similarity`, ролик не попадает в очередь.

Опционально доступна локальная Chatterbox Multilingual. Она устанавливается в
отдельное Python 3.11 окружение по `requirements-tts.txt`; для стабильного русского
произношения рекомендуется собственный голосовой образец с правом использования.

## Подключение YouTube

1. Создайте проект в Google Cloud.
2. Включите **YouTube Data API v3**.
3. Создайте OAuth Client ID типа **Desktop app**.
4. Сохраните файл как `oauth/client_secrets.json`.
5. Выполните:

```powershell
venv\Scripts\python.exe cli.py youtube-auth
```

6. Сначала загрузите один ролик приватно:

```powershell
venv\Scripts\python.exe cli.py youtube-preview ID
venv\Scripts\python.exe cli.py youtube-publish ID --privacy private
```

Только после успешного теста включайте
`publishing.youtube.enabled: true` в `config.yaml`. Новые непроверенные приложения
Google могут публиковать видео только приватно до прохождения аудита.

## Telegram

Добавьте в `.env` токен бота, ID канала и свой числовой Telegram user ID:

```dotenv
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHANNEL_ID=@your_channel
TELEGRAM_USER_ID=123456789
```

Бот должен быть администратором канала. `TELEGRAM_USER_ID` ограничивает пульт
управления одним владельцем: сообщения остальных пользователей игнорируются.
После запуска панели отправьте боту `/start`. Для публикации в канал включите
`publishing.telegram.enabled` в `config.yaml`.

Панель по умолчанию слушает только `127.0.0.1:8765` и не открывает управляющий
API другим устройствам локальной сети. Изменяющие запросы защищены CSRF-токеном
текущего процесса, Host allowlist и проверкой loopback-клиента.

## Расписание Windows

Настройте время в `publishing.youtube.post_times` и запускайте `scheduler.py`
каждые 15 минут. Команда PowerShell без жёстко заданного пользовательского пути:

```powershell
$project = (Resolve-Path .).Path
$python = Join-Path $project "venv\Scripts\python.exe"
$scheduler = Join-Path $project "scheduler.py"
$action = "`"$python`" `"$scheduler`""
schtasks /Create /SC MINUTE /MO 15 /TN "ContentAutomationScheduler" /TR $action /ST 00:00
```

Удаление задачи планировщика:

```powershell
schtasks /Delete /TN "ContentAutomationScheduler" /F
```

## Настройка `config.yaml`

Основные разделы:

- `whisper` — модель, язык и CPU/CUDA;
- `highlight` — адрес Ollama, модель и окно контекста;
- `dorama` — источники радара, голос, хештеги и длительность;
- `episode` — число сцен, громкость оригинала и длительность пересказа;
- `render` — автоматический выбор NVENC/QSV/AMF и качество кодирования;
- `licensed_sources` — источники с лицензиями, разрешение, максимальный размер файла и белый список;
- `publishing` — платформы, приватность и расписание;
- `web.max_upload_mb` — лимит одного пользовательского видео (не более 2048 МБ);
- `paths` — рабочие каталоги и SQLite-очередь.

Канал с отдельным письменным разрешением можно добавить так:

```yaml
licensed_sources:
  approved_channels:
    "UC_CHANNEL_ID": "номер договора или публичная ссылка на разрешение"
```

Не добавляйте сюда приватный текст договора или персональные данные.

### Производительность

По умолчанию Whisper использует `cuda` с `float16`. Если CUDA или нужные библиотеки
недоступны, задача автоматически продолжится на CPU с `int8`. Для компьютера без
NVIDIA укажите `whisper.device: cpu` явно.

Перед первым рендером программа проверяет реальные аппаратные кодировщики и выбирает
первый рабочий в порядке NVENC → Intel QSV → AMD AMF → `libx264`. Выбор выводится в
лог задачи. Его можно зафиксировать через `render.video_encoder`.

Расшифровки сохраняются в `storage/cache/transcripts`. Ключ кэша учитывает путь,
размер и время изменения исходника, модель Whisper и язык. Изменённый файл не получит
устаревшую расшифровку. Проверенные скачанные источники также используются повторно,
а незавершённые прямые загрузки сохраняются как `.part` и продолжаются со старого места.

Быстрые безопасные настройки для ноутбука с 6 ГБ VRAM:

```yaml
whisper:
  model: medium
  device: cuda
  compute_type: auto

licensed_sources:
  download_height: 720
  max_download_mb: 700
```

## Безопасность и приватные файлы

Репозиторий намеренно игнорирует:

- `.env` и все реальные API-токены;
- `oauth/`, Google client secrets и OAuth-токены;
- `input/` с пользовательскими видео;
- `output/` с результатами и тестовой озвучкой;
- `storage/*.db` с очередью;
- виртуальные окружения, логи, субтитры и временные медиафайлы.

Перед публикацией форка проверьте:

```powershell
git status --short
git ls-files
```

Если секрет когда-либо попал в коммит, простого удаления файла недостаточно:
отзовите токен у провайдера и выпустите новый.

Прямые загрузки Wikimedia Commons и Internet Archive принимают только HTTPS URL
из allowlist соответствующей площадки; каждый редирект и сигнатура контейнера
проверяются до передачи файла в FFmpeg.

## Частые проблемы

### `Warning: unauthenticated requests to the HF Hub`

Это не ошибка. При первом запуске Whisper скачивает модель анонимно. Добавьте
собственный `HF_TOKEN` в `.env`, чтобы использовать более высокие лимиты.

### Google OAuth возвращает `403 access_denied`

Добавьте свой Google-аккаунт в **OAuth consent screen → Test users** или переведите
приложение в Production после выполнения требований Google.

### Поиск CC нашёл старый фильм

Современные сериалы редко публикуются с лицензией на переработку. Уточните название
и год либо загрузите собственный/официально лицензированный файл. Не отключайте
проверку лицензии.

### Обработка длинной серии занимает много времени

Пятиминутный результат не означает пятиминутную обработку: Whisper анализирует весь
исходник. На CPU модель `medium` может работать значительно дольше длительности видео.
Для ускорения используйте CUDA или модель `small`. При повторной обработке неизменённого
файла программа возьмёт расшифровку из кэша. Частичная загрузка сохраняется и может быть
продолжена следующим запуском.

### Ролик остался в статусе `publishing`

Это безопасное состояние после аварийного завершения во время внешней загрузки:
система не возвращает такой ролик в очередь автоматически, чтобы не создать дубль.
Сначала проверьте YouTube и Telegram. Только если публикации точно нет, выполните
`python cli.py recover ID --confirmed-not-published`.

### `Ollama: Read timed out (read timeout=60)`

Актуальная версия не обрывает запрос во время долгой загрузки модели или обработки
контекста: сетевое чтение работает в фоне, общий лимит берётся из конкретного этапа,
а кнопка отмены остаётся активной. Модель удерживается в памяти Ollama 15 минут между
запросами. На 6 ГБ VRAM первый большой запрос всё равно может занимать несколько минут.

## Ограничения

- TikTok Content Posting API пока не подключён;
- поиск по Bilibili и Dailymotion используется только как источник метаданных;
- автоматическая проверка не заменяет юридическую оценку конкретного материала;
- YouTube может отказать в монетизации повторно используемого контента даже при
  отсутствии страйка;
- публичная публикация требует ручной ответственности владельца канала.
